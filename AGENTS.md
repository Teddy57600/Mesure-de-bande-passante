# Documentation du projet

À chaque mise à jour de MiniDébit, maintenir un README.md moderne et exact, conformément à la demande de l’utilisateur.

- Conserver la bannière locale, la présentation soignée, les badges de version et de plateforme, la navigation, la table des matières cliquable et les tableaux utiles. Actualiser la table des matières lorsque les sections changent.
- Actualiser les fonctionnalités, les réglages par défaut, les instructions et les captures lorsque le comportement correspondant change.
- Utiliser uniquement des versions, résultats et caractéristiques vérifiés ; ne pas inventer un statut CI, une licence ou un lien de dépôt.
- Conserver les explications utiles et regrouper les détails longs dans des sections repliables si cela facilite la lecture sur GitHub.
- Lors de la livraison, synchroniser le README et les visuels dans dist/MiniDebit, puis actualiser l’archive de la version livrée.
- Une modification documentaire seule ne nécessite pas une nouvelle version ni une relance du widget.
